# Record Task Skill

## 1. 목적

이 스킬은 TASK 실행 결과를 재현 가능하게 기록한다.

주요 기록 위치:

- `ops/logs/TASK-xxx.log.md`

필요한 경우 TASK가 허용한 범위 안에서 다음 문서도 갱신할 수 있다.

- `docs/08_ops/status/evidence_log.md`
- `docs/08_ops/status/status_report.md`

## 2. 입력

필수 입력:

- TASK ID
- WBS ID
- objective
- 변경 파일 목록
- 구현 요약
- 검증 결과
- 리뷰 결과
- 남은 위험
- 커밋 메시지
- 커밋 해시

## 3. 절차

1. TASK ID와 WBS ID를 확인한다.
2. `ops/logs/TASK-xxx.log.md` 파일을 생성하거나 갱신한다.
3. 구현 요약을 기록한다.
4. 변경 파일 목록을 기록한다.
5. 검증 명령과 결과를 기록한다.
6. 리뷰 verdict와 리뷰 메모를 기록한다.
7. 남은 위험 또는 후속 작업을 기록한다.
8. 커밋 메시지와 커밋 해시를 기록한다.

## 4. 기록 원칙

- 사실만 기록한다.
- 실행하지 않은 검증을 실행했다고 쓰지 않는다.
- 실패한 검증을 숨기지 않는다.
- 리뷰 결과를 임의로 바꾸지 않는다.
- TASK 범위 밖 문서는 수정하지 않는다.

## 5. 하드 룰

- 증거를 조작하지 않는다.
- 실패한 작업을 완료로 기록하지 않는다.
- 커밋하지 않는다.
- 상위 문서를 임의로 수정하지 않는다.
