# Validation Checklist

## 공통 체크
- [ ] 요구사항과 변경 내용이 일치한다
- [ ] 범위 밖 변경이 없다
- [ ] 테스트 결과가 기록되었다
- [ ] typecheck 결과가 기록되었다
- [ ] lint 결과가 기록되었다
- [ ] build 결과가 기록되었다
- [ ] evidence가 업데이트되었다
- [ ] handoff가 업데이트되었다

## 사용자 검증 체크
- [ ] 사용자 검증 필요 여부가 명시되었다
- [ ] 사용자 검증이 필요한 경우, 검증 대상(화면/경로/상황)이 작성되었다
- [ ] 사용자 검증이 필요한 경우, 단계별 검증 절차가 작성되었다
- [ ] 사용자 검증이 필요한 경우, 기대 결과가 작성되었다
- [ ] 사용자 검증이 필요한 경우, 실패 시 확인 포인트 또는 이상 징후가 작성되었다
- [ ] 사용자에게 바로 전달 가능한 수준으로 작성되었다
- [ ] 자동 검증으로 충분한 작업은 사용자 검증 불필요 근거가 작성되었다

## 문서 작업 체크
- [ ] 문서 경로가 정책과 일치한다
- [ ] 중복 truth를 만들지 않았다
- [ ] 참조 링크가 유효하다

## 코드 작업 체크
- [ ] 계약 위반이 없다
- [ ] 기존 동작 파손이 없다
- [ ] 필요한 검증이 수행되었다
