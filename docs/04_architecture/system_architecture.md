## 1. 목적
이 문서는 시스템의 상위 구조와 책임 경계를 정의한다.

## 2. 상위 구성 요소
- UI / Client
- Application / Orchestrator
- Domain / Business Logic
- Infrastructure / Persistence / External IO

## 3. 책임 경계
- UI: 입력/표시/상호작용
- Application: 유스케이스 조정
- Domain: 핵심 규칙과 상태 변화
- Infrastructure: 외부 시스템 연결

## 4. 의존 규칙
- 상위 계층은 하위 세부 구현에 직접 의존하지 않는다.
- 계약은 contracts 문서로 관리한다.
- 구조 변경 시 ADR을 남긴다.
