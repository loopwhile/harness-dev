## User Decision

사용자는 검증 완료 후 아래 중 하나를 선택한다.

| 선택 | 의미 |
|---|---|
| APPROVED | 검증 통과. 다음 기능 그룹으로 진행한다. |
| REJECTED | 검증 실패. 수정 후 재평가가 필요하다. |
| REQUEST_CHANGES | 부분 수정 필요. 지적된 항목만 수정 후 재검증한다. |
| DEFERRED | 보류. 후속 조치를 결정한 뒤 진행한다. |
